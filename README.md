# GomycodeLabPhaseProject
Test cases and analysis for PrestaShop Demo project.

Summary of Work Done
Test Analysis & Design:
Evaluated the functional capabilities and user experience of the PrestaShop Demo platform. Designed a detailed Test Cases Matrix translated into English covering core user journeys: User Authentication (Registration, Login, Password Recovery), Product Catalog (Search, Advanced Filtering, and Price Sorting), Shopping Cart management, and the End-to-End Checkout flow.

Documentation & Structuring:
Organized all test criteria using standardized test case attributes including campaign name, test suites, test IDs, test titles, types, preconditions, step-by-step instructions, test data, expected results, and execution statuses.

Publishing & Version Control:
Successfully created a remote repository on GitHub to manage project deliverables. Configured the repository documentation with a structured markdown file (README.md) housing direct access links to the cloud-hosted test sheet, ensuring clean version control, transparency, and seamless sharing with instructors and reviewers.
